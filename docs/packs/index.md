# Create reference packs

Make a collection from your own recordings, or work with an AI agent to annotate
footage. Both use the same pack format and validation tools.

**Availability:** the creator and pack-management features described here are in
development for Hyper Chamber 1.1.0. The published desktop download is still 1.0.0.

## Start with the desktop editor

[Make your first pack](first-pack.md). Add a short replay, capture key moments and
enter its inputs and execution notes. Preview it before exporting a `.hcpack` file.
The desktop app includes its tools; you do not install Node, ffmpeg or an AI agent.
This first editor accepts already-trimmed MP4 or WebM recordings.

## Work with an AI agent

[Use the pack-authoring skill](ai.md) to create or edit a workspace through the
same tools. It helps keep IDs, source attribution and pack editions consistent.
You review the extracted inputs and timing claims; a successful validation does
not establish that a combo works in the current game version.

## Try the example

The [sample workspace](https://squid-quarters.github.io/hyper-chamber/create-packs/downloads/sample-workspace.zip) contains a four-second
synthetic recording and one draft reference. Open the extracted folder in the
creator, or [import the sample pack](https://squid-quarters.github.io/hyper-chamber/create-packs/downloads/sample.hcpack) to inspect the result.
It is labeled **Not gameplay**. To make your own collection, start a new workspace
or fork the sample pack so it receives independent IDs. Replace the sample media,
profile and annotations before treating it as a real reference.
The sample has its own [reuse permission](sample/COPYING) and [source record](sample/PROVENANCE.md).

## Keep a pack up to date

[Manage installed packs](manage-packs.md) for importing, updating, removal and
recovery. [Format and tool reference](format.md) covers editable files, editions,
execution revisions and legacy packs.

A workspace is your editable source. An exported pack is a portable copy you can
import or share. Keep the workspace folder if you want to update that collection
later. Your private practice notes remain in your library, outside the pack.
