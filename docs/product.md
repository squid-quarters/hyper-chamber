# Hyper Chamber product scope

Hyper Chamber is a fast, visual Street Fighter 6 compendium, initially supporting Dhalsim only. Its name pays homage to the Hyperbolic Time Chamber. The project has its own Squid Quarters repository and can be linked or integrated into the main website later.

The core unit is an individual reference: a combo, setup, or response. A reference combines conditions, persistent notation, selected visual moments, a dedicated replayable clip, and short notes. Search and filters should answer “I remember a route starting with this move; help me find and inspect it.”

## First version

- Browse and search by notation, move name, situation, and outcome text.
- Filter type/situation, save references, follow related alternatives.
- Keep entry selection and filters in a shareable URL; restore through browser history.
- Replay, loop, slow down, and seek from a keyframe to its point in the selected entry clip.
- Focus view keeps a selected reference readable beside the game.
- Personal status, notes, and favorites live in browser storage with JSON backup.
- SF6 Lab supplies linked guides and longer explanations. Its organization informs terminology, not copied page layouts or an imported guide database.

## Boundaries

This is not a lesson sequence or a mastery assessment. Personal status is self-reported. The application does not detect gameplay, diagnose failed inputs, capture video, control SF6, or offer global keyboard shortcuts while the game has focus.

No accounts, cloud synchronization, public authoring editor, live frame-data feed, public hosting, or current-patch verification is part of this first version. The local web app is not yet an installable offline PWA. Support for other characters is a future content decision; no placeholder character library is shown.

## Evidence and next content

Review individual source intervals visually. Keep draft interpretations separate from reviewed entries. A technique's kind, starting situation, and outcome are separate fields; one canonical entry can be found through several queries without duplicating it.

Test the compendium during actual practice: time to locate a route, effort to replay a transition, and ease of retaining the important conditions and inputs. Grow the library after this interaction proves useful.
