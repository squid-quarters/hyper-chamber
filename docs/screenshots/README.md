# README screenshots

Captured from Hyper Chamber v1.0.0-beta.1 on 13 November 2026, using the compiled browser interface at commit `555bd079eca154ee6ecce44a79aa1502fc6a5bb1`. These are real app screens in a fresh browser session, converted to WebP without retouching. Each image is one viewport, rather than a stitched page capture.

The capture used a fresh local SQLite library initialized with the repository's full development catalog and media fallback. It shows the interface with that content available; the desktop app's bundled starter contains three Dhalsim demonstrations, and additional references need their character packs.
