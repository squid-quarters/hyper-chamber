# Hyper Chamber design

The product is a compact fighting-game compendium, populated with Street Fighter 6 / Dhalsim and Ryu references. A compact character selector changes the library, guide destination and character-specific notation help. A searchable tile library opens a dedicated practice view. Inputs sit above the replay; key moments, move explanations, conditions and personal notes continue below. Back to library restores the originating tile, filters and scroll position. Previous/Next follow the current filtered result set, including Saved when selected. Quick switch searches current results, Saved or the entire library without leaving practice.

The MVP adopts Chamber: ivory, ink and aged brass, with the Hourglass H mark. Flat tiles and shared edges group references and controls. Condensed headings contrast with readable sans-serif labels and monospace input notation. Source footage supplies the main imagery. There are no invented statistics, rewards or completion thresholds. Semantic color roles live in `apps/web/src/app.css`; inverse input surfaces have explicit text, accent and focus colors.

Each entry separates type, situation and outcomes. Persistent notation precedes the replay and annotated filmstrip; frame selection pauses and seeks the actual local clip. Playback is explicit and silent. Tap the picture to play or pause; drag horizontally to inspect relative to the grab moment, then release to hold the result. Vertical touch movement scrolls the page. The timestamp and progress line appear only during inspection or keyboard focus. A compact toolbar keeps playback, replay, loop, speed and click-to-nudge controls available. Loop preference is remembered separately from learner data; native looping runs only during playback so a paused end inspection stays in place. The media component retains native controls before enhancement. The library itself requires JavaScript to open practice and provides a guide link when JavaScript is disabled.

The video surface is a keyboard-operable button, and player shortcuts remain scoped to focused clip controls. A non-live position description and a polite announcement after an explicit seek or pause provide timing feedback without narrating continuous playback. The clickable key moments and nudge buttons provide alternatives to dragging. Personal favorites, status and notes are local to the learner and visually separate from source verification.

Input sequences use one ordered path of moves, with each authored label and cue beside its notation. SVG connectors show order only; they do not imply a cancel, a link, a timing window or a branch. The plain-text sequence remains available in a disclosure. The practice overview wraps every path horizontally, including longer routes. Full move labels, cues and actor identities remain in the ordered markup and in an explanation disclosure below the replay. The overview and replay share a viewport-sized grid on desktop; narrow or enlarged layouts can scroll naturally. Semantic HTML carries the sequence, so the reading order and text remain available independently of SVG. Move nodes do not seek the video: input steps and captured frames have no authored mapping yet. Future timing or transition annotations need reviewed content before they can change a connector's meaning.

Search, type, situation, self-reported practice status, saved state and entry selection are reflected in the URL. Entry selection creates history; filter edits replace the current history entry. An entry parameter opens practice directly; filter-only URLs stay in the library. Choosing a reference focuses its heading. Escape returns to the library outside text fields and dialogs; Ctrl/Cmd+K opens Quick switch. The chooser uses a native dialog with search, arrow-key navigation and Enter selection. Its Escape dismissal returns focus to its invoker. Switching entries resets the keyed media instance; returning to the library removes and pauses it. Backups merge by entry ID with imported values replacing matching personal entries; unknown IDs remain preserved while visible saved counts are scoped to the current library.

The library is a responsive, text-led grid with all search and filter controls retained. On desktop its filters stay available while browsing. The practice navigation remains reachable above the replay while reading notes; mobile uses the same two views with natural vertical flow. Native dialogs provide notation help and backup controls. Controls have visible focus states and content does not depend on color alone.

Structure-only inspiration supplied by the research pass: [Zoom search and tagged clips](https://mobbin.com/screens/8ac631df-2124-44da-8199-2346d67375ac), [Vimeo result filtering](https://mobbin.com/screens/61a592c7-dc5b-40ce-bfb2-51498a6b68dc), and [Loom saved navigation](https://mobbin.com/screens/f2cf240e-0a9c-4935-ac4a-20c76c231c8d). These inform navigational conventions rather than styling. Design is implemented natively in Svelte and CSS.

For the sequence refinement, [Attio](https://mobbin.com/screens/b1d64fe7-82a9-42dd-9487-6385ac347cc6) and [incident.io](https://mobbin.com/screens/45365384-2ea7-4a55-bb83-2384579937f5) show vertically connected steps with information attached to each step. Those workflow editors supply structural examples only; Hyper Chamber keeps its existing palette, type and read-only reference behavior. The horizontal adaptation and text disclosure are design decisions for this compendium.

The selected browsing direction follows the tile-library exploration: [Loom](https://mobbin.com/screens/5d0ce4ff-a6cc-4c5b-ac3c-fa78e2b1a59a) and [Arcade](https://mobbin.com/screens/d71b6ebd-e45f-48de-92f4-92642e4c699f) supplied structural examples of searchable media grids. Dedicated practice and the input-before-replay hierarchy follow the requested training workflow. Previous/Next and Quick switch keep a chosen result set within reach without retaining a second scrolling pane.
