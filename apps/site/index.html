Combo references for training mode.

Hyper Chamber keeps inputs, short replays and execution notes together while you practise Street Fighter 6. Use the native desktop app, or open its library on your phone or tablet over your local network.

View on GitHub Beta downloads

Beta in development. Version 1.0.0-beta.1 is a test release.

Find a route for the situation.

Choose a character, then filter for punishes, corner carry, oki, anti-air or cash-out routes. Search move names or inputs when you know what you’re looking for.

Loop a demonstration, slow it down or drag across the picture to inspect a transition. Save routes to return to, add timing notes and keep track of what you’ve practised.

Platforms

The desktop app holds your library. A phone or tablet can access the same references and notes through its browser.

macOS Native app · Beta
Built and tested on Mac. The app runs locally and keeps your library on your computer.
Phone & tablet Browser access
Enable device access in the desktop app, then open its address in your browser on the same local network. Keep Hyper Chamber running on the computer while you practise.
Windows Native app · Beta
For Windows 10 or later, 64-bit. The installer includes the runtime it needs.

Homebrew on macOS

Install the Mac app from the official Squid Quarters tap:

brew install --cask squid-quarters/tap/hyper-chamber@beta

Homebrew installs the same app and uses the same first-launch checks.

Before opening the app

The Mac beta is ad-hoc signed and is not notarized by Apple. macOS may block its first launch; follow Apple’s instructions for opening an unnotarized app. The Windows installer is unsigned.

About the beta

The app starts with three Dhalsim demonstrations. Add character content packs from the release page for the rest of the collection. The screenshots on this page show the full development library.

Each reference links back to its source, with review notes that distinguish checks against the video from testing in-game.
