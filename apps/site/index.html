Homebrew on macOS

Install from the Squid Quarters tap:

brew install --cask squid-quarters/tap/hyper-chamber

Homebrew installs the same app. macOS applies the same first-launch checks.

First Launch

The Mac app uses ad-hoc signing and is not notarized by Apple. macOS may block its first launch; follow Apple’s instructions for opening an unnotarized app. The Windows installer is unsigned.
